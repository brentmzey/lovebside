# Welcome to B-Side

B-Side is a **production-ready messaging application** built with **Kotlin Multiplatform (KMP)** and **Compose Multiplatform**. It demonstrates a "Supercharged" architecture sharing **100% of business logic** and **99% of UI code** across Android, iOS, Desktop, and Web.

## What is B-Side?

B-Side is both a **fully functional messaging app** and a **reference architecture** for building cross-platform applications with Kotlin Multiplatform. It showcases:

- 🚀 **Real-time messaging** with Server-Sent Events (SSE)
- 💬 **Modern chat features**: typing indicators, read receipts, reactions, threads
- 🎨 **Material 3 Design System** with dynamic theming
- 🏗️ **Clean Architecture** with ViewModels, Repositories, and Use Cases
- 🔐 **Secure authentication** and credential management
- 📱 **True multiplatform**: One codebase, multiple platforms

## Key Features

### Real-Time Communication
- Instant message delivery with SSE
- Live typing indicators
- Read receipts and delivery status
- Message reactions with emoji
- Threaded conversations

### Cross-Platform UI
- 99% shared UI code with Compose Multiplatform
- Platform-adaptive layouts
- Responsive design for all screen sizes
- Native look and feel on each platform

### Production-Ready Architecture
- Clean separation of concerns
- Dependency injection with Koin
- Coroutines and Flow for async operations
- Offline-first data synchronization
- Comprehensive error handling

## Technology Stack

### Frontend
- **Kotlin Multiplatform**: Shared business logic
- **Compose Multiplatform**: Shared UI framework
- **Voyager**: Navigation
- **Koin**: Dependency injection
- **Ktor Client**: HTTP networking
- **Kotlinx Serialization**: JSON parsing

### Backend
- **Ktor Server**: REST API gateway
- **PocketBase**: Real-time database
- **Redis**: Caching layer
- **Docker**: Containerization

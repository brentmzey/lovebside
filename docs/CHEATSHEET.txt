  2. Wait for Gradle sync
  3. Device Manager → Create Virtual Device (Pixel 6 Pro, API 34)
  4. Start emulator ▶️
  5. Select device from dropdown (top toolbar)
  6. Click Run ▶️ (green play button)

  OR from terminal:
    ./gradlew :composeApp:installDebug

## 🚀 Core Commands

If you have sourced `.envrc`, these commands are available directly in your terminal:

- `setup`: Initialize your local development environment.
- `build`: Build all project modules.
- `start`: Launch the backend and core client applications.
- `test`: Run the comprehensive messaging test suite.

For more specialized scripts, see the `scripts/` directory.
